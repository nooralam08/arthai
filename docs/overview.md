# ArthAI Documentation

Welcome to the ArthAI project documentation.

## Phase 1: Project Foundation

In Phase 1, the repository establishes the core full-stack foundation:
- **`client/`**: React + TypeScript + Vite frontend with Tailwind CSS styling.
- **`server/`**: Express + TypeScript backend providing a `/api/health` check endpoint.
- **`tests/`**: Reserved for integration and end-to-end test suites.
- **`docs/`**: Architecture, guides, and documentation.
